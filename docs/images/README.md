# README 界面图片

这些 PNG 是 OpenButler 实际页面的截图，使用独立本地 PostgreSQL 中人工构造的演示数据。

- dashboard.png：首页与家庭待办概览。
- ai-product-import.png：PDF 产品资料卡演示状态，不是对真实用户文件的识别结果。
- product-library.png：虚构家电、说明书文件名和使用笔记。
- mobile-tasks.png：手机尺寸的待办列表。

没有读取生产数据库、云存储、真实聊天或绑定信息；虚构文件没有上传到任何第三方服务。演示账号、数据库和截图辅助脚本不随项目发布，正常安装也不会自动导入这些数据。
